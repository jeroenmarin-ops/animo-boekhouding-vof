# VOF Boekhouding herbouwd

1. Voer eerst `rebuild-vof-functions.sql` uit in Supabase SQL Editor.
2. Vervang daarna je huidige GitHub-bestanden door `index.html` en `.nojekyll`.
3. Verwijder oude `app.js` en `styles.css`, want deze versie staat volledig in één bestand.
4. Wis Safari-websitegegevens of herlaad zonder cache.

Supabase URL en publishable key zijn behouden.
